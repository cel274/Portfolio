# Portfolio

Personal static portfolio website hosted on GitHub Pages.

## Stack

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JS (no frameworks or external dependencies)

## Local Preview

You can open `index.html` directly in any web browser, or serve it locally:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Then visit `http://localhost:8000`.
